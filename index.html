AI 마에스트로 자율 스터디 · 4회차 미션

회의록 작성 에이전트 발표자료 PDF 하나를 넣으면 「회의록」 양식 한글 문서가 나옵니다

회의 제목과 자료를 주면 자료를 읽고 본문을 쓰고, PDF 안의 개념도·화면 캡처를 찾아 골라 캡션까지 달아 관공서 「회의록」 양식 그대로 HWPX 문서를 만듭니다. 서식은 기존 양식 파일의 자원을 그대로 참조하므로 글꼴·여백·표·쪽번호가 원본과 같습니다.

06까다로웠던 부분

단순 치환으로는 안 되는 지점들입니다. 만들면서 실제로 막혔고 고친 것만 적었습니다.

서식을 원본과 똑같이
  • HWPX 는 zip 안에 XML 이 든 형식입니다. 서식을 새로 만들지 않고 기존 양식 파일의 자원을 그대로 참조했습니다.
  • header.xml 의 글꼴·문단·테두리 정의는 건드리지 않고 본문용 자원만 추가(테두리 1 · 글자 8 · 문단 10개)
  • section0.xml 은 제목표 값 칸 6개와 본문 칸 하나만 교체. 용지·여백·쪽번호와 표제 박스는 손대지 않음
발표자료에서 그림 찾기
  • 쪽 안의 이미지·벡터 도형 위치를 격자에 찍고 붙어 있는 것끼리 묶어 하나의 그림으로 봅니다
  • 배경판·로고·머리글은 크기로, 간지 슬라이드는 글자 수로 걸러냅니다
  • 빈 프레임(캡처가 안 붙은 빈 박스)은 저해상도로 다시 렌더해 배경색과 다른 픽셀 비율을 재서 판단합니다 — 실제로 후보 45장 중 7장이 빈 껍데기였습니다
  • 발표자료 폰트가 괄호·화살표를 CJK 호환 문자로 심어 둔 경우 (㏙2단계㏚) 되돌리고, 뜻이 애매한 글자는 고치지 않고 보고합니다
표는 자동으로 계산
  • 열 폭을 내용 길이에 맞춰 배분하고, 한 줄에 들어가는 열은 가운데· 줄바꿈이 생기는 열은 왼쪽으로 정렬까지 자동 결정
  • 같은 값이 이어지면 ^ 로 세로 병합, 행 앞 = 로 합계행 음영
  • 행·열이 뚜렷한 표 그래픽은 그림이 아니라 표로 옮기도록 지침에 넣었습니다. 글자가 선명하고 쪽 경계에서도 잘 흐릅니다
만들고 끝내지 않기
  • 생성 후 한글로 PDF 로 변환해 쪽별 이미지로 렌더하고, 표 잘림·그림 넘침·쪽수 초과를 직접 확인합니다
  • 자료에서 확인되지 않은 항목은 empty_fields 로 보고해 비어 있음을 감추지 않습니다
  • 자료에 없는 내용은 만들지 않고 「검토 필요사항」 에 남깁니다
한계 — 표나 그림이 쪽 경계에 걸리면 한글이 통째로 다음 쪽으로 넘겨 앞 쪽 아래가 비어 보일 수 있습니다. 도구가 고칠 수 없는 부분이라 미리보기로 확인하고 절 순서나 그림 위치를 조정해야 합니다. 또한 결과 확인과 PDF 변환에 한컴오피스 한글이 필요합니다(LibreOffice 는 HWPX 를 읽지 못합니다).

08설치

저장소를 내려받아 설치 스크립트를 실행하면 ~/.claude 아래로 복사됩니다.

Windows (PowerShell)
git clone https://github.com/noheunyu1126-spec/claude-meeting-minutes-hwpx.git
cd claude-meeting-minutes-hwpx
.\install.ps1
pip install lxml pymupdf pywin32
준비물
  • 한컴오피스 한글 — 결과 확인·PDF 변환(Windows)
  • Python 3.10+ — lxml, PyMuPDF, pywin32
  • Claude Code — /회의록 방식에만 필요

설치 후 defaults.example.json 을 defaults.json 으로 복사해 작성자·관리자·장소를 적어 두면 매번 입력하지 않아도 됩니다.
